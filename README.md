# British Airways 2018 — Trust Center (compliance)

Landing corporativa + artigo **Aprendizados** sobre o caso British Airways 2018 e a multa da ICO (Information Commissioner's Office), elaborados para o trabalho de ADS (Análise e Desenvolvimento de Sistemas).

## Conteúdo

- `index.html` — Trust Center (visão geral, pilares, governança, Insights)
- `aprendizados.html` — artigo completo com diagramas
- `assets/` — diagramas do estudo
- `styles.css` / `app.js` — layout e navegação

## Como abrir

Abra `index.html` no navegador ou sirva a pasta estaticamente:

```bash
python3 -m http.server 8765
```

Depois acesse `http://127.0.0.1:8765/`.
